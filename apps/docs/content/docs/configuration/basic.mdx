## `DASHDOT_WIDGET_LIST`

Selects which widgets to show on the dashboard.

The available options are: `os`, `cpu`, `storage`, `ram`, `network`, `gpu`.

- type: `string (comma separated list)`
- default: `os,cpu,storage,ram,network`

## Advanced history

The **Advanced** button at the top right opens synchronized history charts for
CPU/NVMe temperatures, average CPU load, network traffic, and memory usage.
**Normal** returns to the original dashboard. The selected mode is remembered
in the browser; single-widget embeds are unchanged.

History is sampled every 10 seconds and retained for **24 hours**. Period buttons,
zoom/pan controls, drag selection, Ctrl/Command + wheel, and the timeline handles
change the shared time range. Zooming requests more detail from the server;
downsampling retains extrema instead of hiding short peaks. Times use the browser's
local timezone. CPU temperature follows `DASHDOT_CPU_TEMPS_MODE`; NVMe temperature
is the hottest available drive. Network charts show interface traffic, not the
periodic Internet speed test. Memory shows active bytes as a percentage of total RAM.

### `DASHDOT_HISTORY_ENABLED`

- type: `boolean`
- default: `true`

History collection keeps the configured CPU, memory, network, and NVMe sensor
streams subscribed even with no browser open. Set this to `false` to stop
historical collection. When enabled it also keeps those streams running if
`DASHDOT_DISABLE_BACKGROUND_STATS_COLLECTION=true`. Temperature collection still
requires the respective `DASHDOT_ENABLE_CPU_TEMPS` / `DASHDOT_ENABLE_STORAGE_TEMPS`
settings and functioning sensors.

### `DASHDOT_HISTORY_DIRECTORY`

- type: `string`
- default: `/data/history` in containers; `./.dashdot-history` from source

Mount a persistent writable volume at `/data` in Docker/Podman, for example
`-v dashdot-data:/data`. Use one Dashdot writer per history directory. Daily JSONL
files are flushed every minute and on graceful shutdown; a forced termination can
lose the last minute. History is also cached in memory with a bounded sample count.
Files from expired days are removed; the boundary day's file may contain records
older than 24 hours, which are excluded from memory and queries. Other filenames
in this directory are never removed.

History starts accumulating when this version is installed. Restarts reload
persisted readings, and missing sensors or collection downtime appear as gaps.
If persistence fails, Advanced displays a warning and collection continues in memory.
History is served over the existing socket connection, including behind a routing
subpath; `/history?from=<epoch-ms>&to=<epoch-ms>&points=1000` is additionally
available when integrations are enabled. Responses are bounded to 2,000 points.

## `DASHDOT_PORT`

The port where the express backend is running (the backend serves the frontend, so it is the same port for both).

- type: `number`
- default: `3001`

## `DASHDOT_ROUTING_PATH`

The path where dash. is being served. This is useful if you want to run dash. behind a reverse proxy on a sub-path
(e.g `https://example.com/dashdot` would need a value of `/dashdot`).

- type: `string`
- default: `/`

## `DASHDOT_PAGE_TITLE`

If you want to show a custom string in the browser page title.

- type: `string`
- default: `dash.`

## `DASHDOT_DISABLE_INTEGRATIONS`

Disables support for integrations. This does two things: disable CORS and disable open API endpoints.

- type: `boolean`
- default: `false`

## `DASHDOT_DISABLE_BACKGROUND_STATS_COLLECTION`

Disables background collection of metrics.

- type: `boolean`
- default: `false`

## `DASHDOT_SHOW_DASH_VERSION`

If you want to show the version number of your dash. instance on the bottom right of the page, or alternatively on the GitHub icon (hover).

The available options are: `bottom_right`, `icon_hover` and `none`.

- type: `string`
- default: `icon_hover`

| `bottom_right`                                                                                            | `icon_hover`                                                                                                      |

## `DASHDOT_USE_IMPERIAL`

Shows any units in the imperial system, instead of the default metric.

- type: `boolean`
- default: `false`

| `false`                                                                                                   | `true`                                                                                                                  |
| --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ![CPU widget with temps in celsius](/img/cpu_view_temps.png) | ![CPU widget with temps in fahrenheit](/img/cpu_view_temps_fahrenheit.png) |

## `DASHDOT_ALWAYS_SHOW_PERCENTAGES`

To always show the current percentage of each graph in the top-left corner. Without enabling this,
they will only be shown on lower resolution devices (mobile phones).

- type: `boolean`
- default: `false`

| `false`                                                                                                      | `true`                                                                                                             |
